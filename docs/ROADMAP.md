# Roadmap

更新日期：2026-07-31

## 当前状态

自托管 MVP 已部署到 `nltnpe.cn`。Node.js、MySQL、Garage、访问口令、邮箱密码登录、额度与并发控制、三种 Vidu 工作流和可选 Gemini 分析已经形成最小闭环。

## P0：完成业务验证

- 配置生产 Vidu Key，使用非敏感素材完成三种生成路径的真实冒烟测试。
- 配置 Gemini Key，验证 Files 上传、ACTIVE 等待、Interactions 分析与缓存命中。
- 核对 Vidu 能读取经应用授权提供的 Garage 媒体路由。
- 为 MySQL 与 Garage 建立定期加密备份和恢复演练。
- 增加应用、MySQL、SSH 隧道与 Garage 的可观测性和故障告警。

## P1：结果持久化与运营

- 将成功视频自动归档到 Garage，避免 Vidu 短期结果链接失效。
- 增加任务取消、失败重试和额度退款策略。
- 增加运营用量报表、Provider 成本核算与异常额度告警。
- 补齐管理员首次初始化向导，消除固定 Seed 邮箱依赖。

## P2：商业化

- 接入支付、套餐或兑换码。
- 增加团队空间、共享素材库和成员用量控制。
- 增加生成模板、批量任务与客户项目交付功能。

## 暂不实施

- 复制 Vidu 的全部 API 能力。
- 在未验证真实负载前引入独立任务队列集群。
- 未完成隐私、计费和内容合规设计前开放公共注册。
