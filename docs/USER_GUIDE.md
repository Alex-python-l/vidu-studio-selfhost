# Vidu 创作台使用手册

本文面向创作者、管理员和支持人员。开发、环境配置和生产发布请阅读
[README](../README.md)与[部署与运维手册](DEPLOY.md)。

## 1. 角色与权限

| 角色 | 创作工作台 | 账户与额度 | 管理后台 |
| --- | --- | --- | --- |
| `user` | 可使用 | 仅本人 | 不可访问 |
| `support` | 可使用 | 仅本人 | 只读：Key 状态、用户、口令、额度与审计 |
| `admin` | 可使用 | 仅本人 | 可管理 Key、口令、用户、角色、额度和审计 |

系统会保护最后一名活跃管理员：不能删除、停用或降级。用户被删除后会立即
退出并从管理列表隐藏，但历史任务、额度账本、媒体索引和审计仍保留。

## 2. 注册与登录

### 2.1 新用户使用访问口令注册

管理员可以提供：

- 一条邮箱专属邀请链接；或
- 一个可手动输入的访问口令。

注册步骤：

1. 打开邀请链接，或进入 `/login` 后选择“使用访问口令注册”。
2. 输入邮箱。
3. 如果不是专属链接，输入管理员提供的访问口令。
4. 设置并确认 8–128 个字符的登录密码。
5. 提交后进入创作台。

注意：

- 访问口令只用于首次注册和发放初始额度，不是登录密码。
- 当前注册只检查邮箱格式，不验证邮箱归属。请使用自己能长期识别的邮箱。
- 已注册邮箱不能再次使用访问口令覆盖密码。
- 初始 credits、并发上限和每日额度由该访问口令的模板决定。
- 管理员后来修改口令模板，不会回写已经注册的账户。

### 2.2 已有用户使用密码登录

1. 打开 `/login`。
2. 选择“密码登录”。
3. 输入注册邮箱和密码。
4. 登录后返回此前请求的页面，默认进入 `/studio`。

密码区分大小写，长度为 8–128 个字符。

### 2.3 可选 Email OTP

只有运维完整配置 Supabase 与 Turnstile 时，登录页才会显示“邮箱验证码”。
OTP 是已有账户的兼容入口，不用于绕过访问口令注册。

系统不会在 OTP 请求阶段透露某个邮箱是否已注册。

### 2.4 退出

在工作台侧栏或账户页点击“退出”。退出会撤销当前应用会话，并返回公开页面。

## 3. 工作台概览

工作台主要分为四个区域：

1. **左侧导航**：参考生成、动作迁移、语言、主题、刷新、账户、管理和退出。
2. **状态带**：
   - 可用 credits；
   - 正在使用的生成并发槽位；
   - 等待任务数；
   - 累计成功结果数。
3. **创作区**：填写素材、提示词和输出参数。
4. **最近任务**：显示最多 30 条近期任务、输入素材、状态、实际消耗和结果。

参考生成下还有两个子模式：

- **人物替换**：主要和推荐模式。
- **自由参考生成**：多图、多视频和提示词组合。

## 4. 素材准备

### 4.1 站内上传

| 类型 | 格式 | 单文件上限 |
| --- | --- | --- |
| 图片 | JPG、PNG、WebP | 50MB |
| 视频 | MP4、MOV、AVI | 50MB |

上传会自动以 5MB 分块写入 Garage 对象存储。上传中不要关闭页面或切换网络。中断后重新选择
文件即可。

### 4.2 外部 URL

可以使用可公开访问的 HTTP(S) URL。请确认：

- 不需要登录或临时 Cookie；
- Vidu 的服务器可以直接访问；
- 链接在任务生成期间不会过期；
- 返回的是媒体内容而不是 HTML 下载页；
- URL 没有暴露不应公开的个人信息或长期凭证。

大于 50MB 的视频必须使用外部 URL。人物替换若要开启 AI 视频分析，优先上传
本站；本站不会代抓取外链视频供 Gemini 分析。

### 4.3 通用素材建议

- 人物图尽量清晰、正面、无遮挡、单人。
- 动作视频保持主体完整，不要频繁出画。
- 避免强压缩、过暗、过曝或大面积水印。
- 多人原视频要在“要替换的人物”中写明位置、衣着或其他可区分特征。
- 使用无敏感信息、且拥有处理权限的素材。

## 5. 人物替换

人物替换用一张目标人物图替换原视频中的指定人物，同时尽量保留动作时序、
运镜、构图、场景和遮挡关系。

### 5.1 输入要求

- 目标人物图：1 张。
- 原视频：1 个，1–8 秒。
- 要替换的人物：1–100 个字符。
- 补充提示词：可选，最多 2000 个字符。
- 输出清晰度：540p、720p 或 1080p。
- 输出比例：16:9、9:16、4:3、3:4 或 1:1。

上传原视频后，工作台会自动读取时长，并根据源视频方向选择横屏、竖屏或方形
比例。仍可在提交前手动调整。

### 5.2 操作步骤

1. 在“参考生成”中选择“人物替换”。
2. 上传目标人物图，或展开 URL 输入并粘贴图片地址。
3. 上传原视频，或展开 URL 输入并粘贴视频地址。
4. 在“要替换的人物”中描述目标，例如：
   - `画面中央穿黑色上衣的人`
   - `从左数第二位戴帽子的舞者`
5. 需要时填写本次素材特有的补充要求。
6. 确认 AI 视频分析状态。
7. 检查时长、清晰度、比例和预计 credits。
8. 点击“开始替换”。

### 5.3 AI 视频分析

AI 分析默认开启。它会从原视频提取：

- 人物与位置；
- 动作和时序；
- 运镜与构图；
- 场景和关键物体；
- 接触、遮挡和必须保留的连续性；
- 潜在失败风险。

站内视频先上传到 Gemini Files API，文件进入 `ACTIVE` 后再创建分析任务。

状态处理：

- **正在上传/分析**：提交按钮保持锁定。
- **分析完成**：自动解锁，可提交。
- **分析失败**：点击“强制再次分析”，或关闭 AI 分析后使用基础模板提交。
- **复用已有分析**：相同站内视频内容已分析成功，系统直接使用缓存。

关闭分析不会关闭人物替换模板，只是不再加入 Gemini 生成的素材约束。

### 5.4 提示词写法

系统已自动加入人物替换模板。补充提示词只写本次素材特有要求，例如：

- `保留原视频红色雨伞和雨夜霓虹背景。`
- `替换后人物仍穿目标图中的白色外套。`
- `不要改变原视频的手持物体与镜头推进节奏。`

避免重复描述所有动作，或要求和原视频明显冲突的镜头。

## 6. 自由参考生成

自由参考生成使用图片和视频作为一致性参考，再根据提示词生成新视频。

### 6.1 输入要求

- 至少提供一张图片或一个视频。
- 无视频时最多 7 张图片。
- 使用视频时最多 4 张图片。
- 最多 2 个参考视频。
- 1 个参考视频时最长 8 秒。
- 2 个参考视频时每个最长 5 秒。
- 提示词：1–5000 个字符。
- 输出时长：1–10 秒。
- 清晰度：540p、720p、1080p。
- 比例：16:9、9:16、4:3、3:4、1:1。

### 6.2 操作步骤

1. 在“参考生成”中选择“自由参考生成”。
2. 填写可选任务名称，便于在队列中识别。
3. 上传图片，或在图片 URL 区每行粘贴一个地址。
4. 上传视频，或在视频 URL 区每行粘贴一个地址。
5. 输入画面描述。
6. 选择时长、清晰度和比例。
7. 按需开启：
   - **生成配乐**：让 Vidu 自动加入 BGM；
   - **错峰生成**：降低优先级并按上游规则处理。
8. 检查预计 credits，点击生成。

### 6.3 提示词建议

先描述主体和场景，再描述动作、镜头和风格。例如：

```text
保持参考图中角色的面部、发型与服装一致。角色在雨夜街道向镜头跑来，
镜头低机位缓慢后退，霓虹灯在湿地面形成倒影，电影感、真实光影。
```

如果多张图代表不同人物或物体，用位置、衣着和功能区分，不要假设系统理解
文件名。

### 6.4 配乐与错峰

- 配乐可能增加上游实际消耗。
- Q2 模型在 9–10 秒时，配乐可能不生效。
- 错峰任务可能等待更久。
- 页面估算只按基础时长和清晰度计算，最终以任务终态实际 credits 为准。

## 7. 动作迁移

动作迁移让目标角色跟随参考视频中的动作与节奏。

### 7.1 输入要求

- 角色图片：1 张清晰、正面、单人的 JPG/PNG/WebP。
- 动作视频：1 个 MP4/MOV/AVI。
- 项目当前允许 2–30 秒。
- Vidu 当前公开 Motion Sync 文档给出的安全范围是 3–30 秒，生产任务建议
  使用至少 3 秒的视频。

页面会从本地视频自动读取时长，并按每秒 10 credits 估算。

### 7.2 操作步骤

1. 在左侧选择“动作迁移”。
2. 填写可选名称。
3. 上传角色图片或粘贴公开图片 URL。
4. 上传动作视频或粘贴公开视频 URL。
5. 检查自动读取的视频时长。
6. 检查预计 credits。
7. 点击“开始生成”。

### 7.3 素材建议

- 角色正面、全身或大半身完整可见。
- 面部无遮挡，身体比例适中。
- 动作主体尽量只有一人。
- 参考视频不要频繁剪辑或大幅改变镜头。
- 手脚不要长期出画，背景不要和人物颜色完全混在一起。

## 8. Credits、并发和每日额度

### 8.1 三个不同限制

- **可用 credits**：账户当前可以消费的余额。
- **并发上限**：同时处于活跃状态的任务数量。
- **每日额度上限**：按 UTC 日累计允许预留的 credits。

任一限制不足，服务端都会拒绝提交，不只依赖页面显示。

### 8.2 预留与实际结算

提交时：

1. 系统计算预计 credits。
2. MySQL 原子检查余额、并发和每日额度。
3. 通过后立即预留额度。

任务结束时：

- 提交失败：退回全部预留额度。
- 上游实际消耗低于预留：退回差额。
- 上游实际消耗高于预留：补扣差额。
- 重复轮询同一终态不会重复结算。

### 8.3 查看额度明细

进入“账户”：

- 查看可用 credits；
- 查看并发上限；
- 查看每日额度上限；
- 查看最近 50 条额度增减；
- 通过 `taskId` 对照具体任务。

如认为额度异常，把任务 ID 和发生时间交给管理员，不要发送素材 URL 或任何
密钥。

## 9. 任务队列

| 状态 | 含义 |
| --- | --- |
| 上传中 | 正在上传素材或向上游提交 |
| 已提交 | Vidu 已接收任务 |
| 排队 | 等待上游调度 |
| 生成中 | 正在生成，占用并发槽位 |
| 完成 | 可播放结果已返回，并已结算 |
| 失败 | 上游或本站处理失败，页面显示短诊断 |

工作台会自动刷新，也可以点击侧栏“刷新”立即同步。

任务卡会显示：

- 工作流类型；
- 名称、时长、清晰度和比例；
- 状态和实际 credits；
- 输入图片/视频；
- 成功结果或失败原因。

### 9.1 下载结果

Vidu 结果 URL 通常只在 24 小时内有效。任务成功后应立即下载并保存到自己的
长期存储。当前系统不会自动把成功视频归档到 Garage。

### 9.2 清空历史

“清空历史”会永久删除当前账户的成功和失败记录：

- 等待中和生成中的任务会保留；
- 操作无法撤销；
- 不要把“清空历史”当作取消任务；
- 清理前先下载需要保留的结果并记录任务 ID。

## 10. 账户与密码

进入 `/account` 可以：

- 查看账户邮箱和当前限制；
- 设置或修改登录密码；
- 查看额度账本。

修改已有密码时必须提供当前密码。成功后当前设备保持登录，其他设备的应用
会话会被撤销。

如果忘记密码，当前没有邮件找回流程，请联系管理员。管理员可以重置或移除
密码，但会撤销该用户的会话。

## 11. 管理后台

只有 `admin` 和 `support` 可以访问 `/admin`。`support` 是只读模式。

### 11.1 服务 Key

后台会列出：

- 环境 Vidu/Gemini Key 的安全别名；
- 管理员录入的加密托管 Key；
- 当前活跃 Key；
- Vidu 实时 credits、并发和队列；
- Gemini 可用性和本站分析调用统计。

管理员可以：

1. 录入新托管 Key，保存后自动设为活跃。
2. 在已存在的 Key 间切换。
3. 对新 Key 运行只读可用性检测。
4. 删除非活跃的托管 Key。

完整 Key 保存后不会再次显示。环境 Key 不能从后台删除。

### 11.2 创建访问口令

可配置：

- 绑定邮箱；
- 初始 credits；
- 新用户并发上限；
- 新用户每日额度；
- 最大使用次数；
- 1–365 天有效期；
- 是否允许邮箱专属链接；
- 是否允许手动输入。

至少启用一种兑换方式。创建后立即复制口令与邀请链接，后台只保留安全提示，
不要把口令发送到公开群或 issue。

### 11.3 管理访问口令

可搜索口令提示、邮箱或 ID，并按状态筛选。管理员可以：

- 修改额度、并发、每日额度、次数、有效期和使用方式；
- 停用口令；
- 删除口令。

停用或删除只影响后续兑换，不会收回已注册用户的额度。

### 11.4 管理用户

管理员可以：

- 搜索邮箱、姓名或用户 ID；
- 设置 `user`、`support` 或 `admin`；
- 设置账号状态；
- 修改并发上限和每日额度；
- 撤销会话；
- 重置或移除密码；
- 删除用户。

删除是业务软删除：账号立即不可登录，但历史记录保留，且不能从后台撤销。

### 11.5 调整额度

1. 打开目标用户。
2. 输入正数增加、负数扣减。
3. 填写可审计的原因。
4. 点击“写入额度账本”。

额度更新与 ledger 记录在服务端原子执行，管理员操作同时写入审计。

### 11.6 审计

后台分别分页显示：

- 最近额度账本；
- 最近管理员审计。

审计只记录操作元数据，不应出现完整 Key、访问口令、OTP、原始 IP 或媒体 URL。

## 12. 常见问题

### 为什么提交按钮不可用？

依次检查：

- 人物替换的 AI 分析是否仍在进行或已失败；
- 必填素材是否齐全；
- 视频时长是否超限；
- 提示词是否超限；
- 余额、并发或每日额度是否不足；
- 管理员是否配置了可用 Vidu Key。

### 为什么外链视频不能做 AI 分析？

本站不会抓取并转存外链视频供 Gemini 使用。把视频上传本站，或关闭 AI 分析
后直接交给 Vidu。

### 为什么页面估算和实际扣费不同？

页面按项目内基础价格预留，最终以 Vidu 返回的实际 credits 为准。配乐、
错峰、上游价格或实际任务参数都可能产生差额。

### 为什么成功视频后来不能播放？

上游结果 URL 是短期地址，通常只保留 24 小时。请在成功后立即下载。

### 为什么修改访问口令没有改变已有用户额度？

口令参数是“首次兑换模板”，只在新用户注册时写入。已有用户需要管理员在
用户详情中单独调整。

### 为什么删除用户后还能看到历史账本或审计？

这是有意的数据保留策略。删除会撤销会话并隐藏账号，但不会破坏历史业务和
审计证据。

### 为什么 2 秒动作视频可能失败？

项目当前校验允许 2 秒，但 Vidu 最新公开 Motion Sync 文档写的是 3–30 秒。
使用至少 3 秒的动作视频。

## 13. 安全与隐私

- 只上传自己有权处理的素材。
- 开启 AI 分析意味着原视频会发送给 Gemini。
- 不在提示词、任务名称或文件名中写入密钥、密码、身份证号等敏感信息。
- 不向支持人员发送 `.env`、完整 API Key、访问口令或会话 Cookie。
- 外部 URL 应避免长期有效的签名参数。
- 下载完成后按组织的数据保留策略处理本地文件。

## 14. 获取支持时提供什么

建议提供：

- 发生时间和时区；
- 页面和工作流；
- 任务 ID；
- 状态与页面显示的短错误；
- 文件格式、大小和时长；
- 是否使用站内上传、外链、AI 分析、配乐或错峰；
- 浏览器和操作系统。

不要提供：

- 完整 Vidu/Gemini Key；
- `.env.local`；
- 密码、OTP、访问口令；
- 会话 Cookie；
- 包含敏感数据的素材 URL。

管理员和运维排查请继续阅读[部署与运维手册](DEPLOY.md#13-常见故障)。
